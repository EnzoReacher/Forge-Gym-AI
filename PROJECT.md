# FORGE V2 — Project

## Purpose

FORGE helps people improve physical health and capability by turning confusion into one clear, realistic next action.

V2 is a clean product and engineering rebuild. It is not a migration of the V1 interface or architecture.

## Product promise

FORGE must be:

- easy to use, access, read, and understand;
- useful to beginners without limiting experienced athletes;
- honest about what it knows and does not know;
- supportive without manipulation, shame, or fake urgency;
- safe around pain, injury, medical warning signs, eating behavior, and performance-enhancing drugs;
- visually recognizable as FORGE without becoming theatrical or cluttered.

## Product identity

Raw Steel / Spartan / Forge:

- black foundation;
- blood-red primary emphasis;
- burnt-bronze and cold-steel accents;
- discipline, strength, and focus rather than fantasy;
- clarity before effects;
- real user data before decorative metrics.

## V2 first objective

Build and validate one exceptional athlete loop:

1. Enter FORGE.
2. Understand what matters today.
3. Start the intended workout.
4. Log sets with minimal friction.
5. Finish the workout safely.
6. See meaningful progress based on real records.

Until this loop is excellent, FORGE does not add billing, admin analytics, social features, uploads, youth access, broad automation, or production AI complexity.

## Non-goals for the first product milestone

- microservices;
- multiple repositories;
- elaborate admin tooling;
- billing;
- social/community features;
- speculative analytics;
- provider-specific architecture;
- production AI coaching;
- a large settings system;
- porting V1 code for convenience.

## Product rules

1. One clear next move.
2. Fewest reasonable steps.
3. Real actions and real data.
4. Complexity must justify itself.
5. Accessibility is default behavior, not a later phase.
6. Safety beats ego or engagement.
7. Missed sessions are information, not failure.
8. No visible control may be fake.
9. No metric may imply knowledge FORGE does not have.
10. Every major feature must improve the athlete's core journey.
